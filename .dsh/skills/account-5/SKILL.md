# 账号内容 Skill：5

> 蒸馏来源：26 条对标视频 | 版本 v1 | status: auto（用户可编辑，编辑后置 manual_edited）

## 定位
童装萌娃穿搭短视频：前3秒完整穿搭直出+动作打断抢停留，短时长多镜头动态证明，转化型走亲子对话+具体价格对比+材质触摸证明+直播间CTA

## 钩子库
- **完整穿搭直出+强动作打断**｜公式：首帧全身完整造型 + 指镜/挥手/走近/怼镜等强动作（1.3秒内完成）｜示例：小女孩拎起外套怼近镜头微笑，同步露出整套搭配｜用法：展示型穿搭视频首选，前3秒必须同时完成注意力建立与商品首曝｜权重：5
- **换装/换人硬切换断**｜公式：首套造型亮相 → 硬切换下装或换模特 → 第二套造型停留展示｜示例：同款上衣先配A裤，硬切后配B裤，补一个转身行走｜用法：一衣多搭、多SKU矩阵、假期/节日多套穿搭｜权重：4
- **儿童第一人称体验反馈开场**｜公式：孩子亲口说使用结果（暖和/舒服）→ 妈妈承接引出产品｜示例：穿在校服里面好暖和｜用法：保暖、贴身类功能商品的转化视频｜权重：4
- **季节/节日共识痛点**｜公式：俗语或节点点题 → 1.3秒内落到孩子穿搭需求｜示例：一场秋雨一场寒；国庆出游穿搭来袭！｜用法：换季、开学、节假日等强时效选题｜权重：3
- **身份反差/成长感慨文案**｜公式：情绪化短句排比或身份宣言 + 穿衣动作切入｜示例：悄悄变小的衣服、越买越大的鞋子；被养得很好的小孩；放假了，谁也别想认出我｜用法：为常规换装展示注入情绪共鸣，避免纯硬广｜权重：2
- **价格冲突质问**｜公式：原价XX多 vs 现价XX → 追问是否同款 → 现场比对自证｜示例：三百多买的衣服现在才六十几，一模一样同款同版型｜用法：促销、清仓、直播间引流的转化视频｜权重：2

## 叙事模板
- **展示型穿搭快闪（6-10秒）**：前1-3秒：全身完整穿搭直出+强动作打断 → 细节拍：整理袖口/抚平前襟/扣纽扣，突出材质与设计 → 动态证明拍：转身、行走、踢腿、跑跳覆盖正/侧/背 → 换装或场景硬切：制造第二套/第二场景 → 收尾拍：微笑走近、摆姿或海报式全身定格
- **转化型口播链路（12-18秒）**：儿童第一人称体验或季节痛点开场 → 引出产品方案与品类 → 原价与活动价的具体数字对比 → 触摸/拉扯/回弹等现场材质证明 → 具体场景利益（校服内穿、一件顶两件、减少叠穿） → 指向下方动作+明确直播间活动与行动指令
- **两拍造型轮播（每套两拍）**：近景细节：面料、纽扣、领型、工艺 → 全身效果：完整版型与搭配 → 切换场景/景别进入下一套 → 结尾比心/商品叠加图收口

## 节奏
展示型总时长6-10秒、3-6个镜头、单镜1-2秒（可至1.1秒高密度）；转化口播型12-18秒、可用单镜头但口播信息必须排满不铺垫；近景与全景必须交替，禁止长时间停留单一景别；静态展示与动态证明（转身/行走/踢腿）交替推进；材质细节镜头需留够时长让人看清针脚与回弹

## 口播风格
展示型走弱口播：甜感歌词/节奏拟声配乐，动作承担信息，口播不承载卖点；转化型走母子对话式：儿童先用第一人称说体验，妈妈用短句连续输出价格、材质、场景卖点，语气生活化直接，全用具体数字（三百多/六十几），结尾催促式收口；儿童穿搭语气保持活泼可爱，禁播腔

## 钩子公式
- 前3秒完整穿搭直出 + 强动作打断浏览惯性
- 儿童亲口使用结果前置 → 产品方案 → 价格对比 → 触摸证明 → 场景利益 → 直播间CTA
- 原价XX多 vs 现价XX → 是否同款质问 → 现场比对自证
- 季节俗语/节日节点 → 1.3秒落到穿搭需求
- 硬切换装：同款不同下装/不同模特，制造款式矩阵
- 近景细节 → 全身效果 两拍结构轮播多套造型
- 情绪短句排比（成长/身份/反差）+ 穿衣动作切入

## 禁则
- 不做：不做缓慢铺垫或纯文字开场，不在首3秒浪费钩子窗口
- 不做：不做首帧只拍局部或只做人物互动而不露出完整穿搭
- 不做：不做连续相似的正面静态全身镜头，不保留无新信息的重复造型镜头
- 不做：不做只展示正面而缺侧面、背面、动态版型的单角度剪辑
- 不做：不做静态站桩收尾，动态证明镜头必须保留转身/行走/踢腿
- 不做：不用高密度碎切打断穿衣操作与转身的连续性
- 不做：不依赖看不清的小字、模糊标签、背景标识牌或不完整口播传递核心卖点
- 不做：不做只报低价而不给原价参照、不解释是否同款的表达
- 不做：不用柔软保暖等抽象形容词，不做没有触摸/拉扯现场证明的材质口播
- 不做：转化视频结尾不做无明确行动指令的收口，必须给出直播间活动+指向动作
- 不做：展示型无CTA时不强行套用强转化结构，无痛点素材时不硬编痛点和功能证言
- 不做：不让动作或文字遮挡服装关键细节，不让镜头过近裁掉完整搭配
- 不做：不保留与商品关联弱的进食、看手机等废镜头，不加纯氛围镜头稀释卖点
- 不做：不把最强笑容与欢呼过早释放，结尾保留情绪峰值
- 不做：抗菌等级等数字口径发布前必须统一核验，禁止前后不一致
- 不做：多套宣称必须有换装硬切等真实证明，不空喊多套可选

## 打法总结
以萌娃完整穿搭首帧直出+强动作打断抢前3秒，用1-2秒短镜的转身行走踢腿做多角度动态证明，转化型则由儿童体验开场、亲子对话输出具体价格对比与触摸证明，收口直播间CTA
