# 超级复刻管线（从 video-skill 搬运）

源码：`backend/services\super_clone_wan3.py`  
页面：`http://127.0.0.1:8090/super-clone-wan3`

## 步骤

| 步 | 名称 | 做什么 |
| --- | --- | --- |
| 0 | 预处理 | 视频存在、ffprobe 时长、可选 trim、锁 `target_duration`、固定 media_manifest 图N；登记引擎选择（Wan 3.0 / Seedance 2.5） |
| 1 | MiMo | 原视频 → canonical storyboard JSON（只解析，不拼 prompt） |
| 1.5 | 迁移编译器 | storyboard + 产品图/脸图 → 模块化复刻 prompt（含 VOICE_LOCK）。合同见 `compiler-contract.md` |
| 1.6 | 编译产物自查 | 对编译出的动作/律动标签核原片；不符 ⇒ extra-note 写死动作时间轴压过解析标签再重编译（见 SKILL.md「编译产物自查」） |
| 1.7 | 意图匹配闸 | agent 读最终 prompt，对着 BRIEF 边界清单核换产品/换脸/换衣服/换背景/保留项/负向是否都进 prompt；不符 ⇒ 补 extra-note 重编译（0 分，不烧引擎） |
| 1.8 | 引擎参数闸（双引擎） | 核对引擎传参：Wan = 干净参考视频 + 参考图 + audioUrls + 分辨率；Seedance = 参考视频 + 分类参考图（产品/脸/衣/景）+ 音色参考。缺传参能力 ⇒ 标记降级，不静默丢 |
| 2 | Layer 2 Linter | 只修客观错误（物理文本、图N 越界/错绑）。宁漏勿改。见 `linter-contract.md` |
| 3 | 生成（双路线选一） | **Wan 3.0**：参考视频（该段干净原片）+ 图 + prompt → 成片；**Seedance 2.5**：参考视频 + 分类参考图 + 同语义 prompt → 成片。路线在 0 步登记，不在出片后换 |
| 3.5 | 出片抽帧质检 | 对着原片逐秒核动作节奏 + 对着边界清单核脸/产品/字幕水印/背景/皮肤；不符只重跑该段（花钱，先报价） |
| 后-1 | 段间接口自检 | 多段拼成前核三件事：段A 末帧 vs 段B 首帧背景同套 / 两段口播拼接与原片逐字一致（不重说、不漏、不截半句）/ 时间戳无重叠无间隙。**动作不做段间衔接校验**（动作只要求复刻原视频，接口处保留原片硬切即可）。接口不合格 ⇒ 回切段表改切点，不重跑引擎段 |
| 后-2 | 难单拼接 + 声音策略 | 各段按原窗口裁切；`preserve_original` 原声音轨主时钟贴回（实测这条 lane 会自己带出参考视频音轨，交付前按与原片"做差 dB"验，别当契约）；`timbre_swap` 用引擎生成的目标音色轨，**禁止贴回原声**；`rewrite_text` 改口播·音色不变走后处理腿 `voiceover_replace.run_narration_swap`（对成片自己 ASR+分离，只重做改动句、未改句留原声、改动窗口垫回 no_vocals，**不做口型**）；段间接口核口播断句与音色一致 |
| 后-3 | 成片终检 | 视觉 + 动作 + 口播 + 音色 + 接口 + 质感六项全过；失败按原因修对应环节（切点错→改切段；字幕→换干净参考源；口播→音频独立处理；质感→视频增强/调色，不改动作），不盲目整片重跑 |

## 前端默认

- 原片不限时长，>15s 自动 15s 切段拼接
- 产品图必选 1–10
- 产品名必填
- 换脸：上传面部图；只取脸/发型
- 换背景：**图为事实源 + 文字补细节**（`--scene-image` 传目标背景图，进引擎作场景 图N，2026-10-31 定；`--scene-text` 只补图里没有的细节，冲突以图为准；没图时纯文字）
- 换衣服：上传目标服装图；保留的袜/鞋/配饰在 BRIEF 登记为保留项
- 换音色：传目标音色参考音频（`--voice-audio`，1–15s 干净人声）；文案不改仍逐字继承原视频，原声不贴回
- 成片默认无字幕、无花字、无账号水印

## 引擎选择（保留两条路线）

| 引擎 | 优先场景 | 传参要点 | 注意 |
|---|---|---|---|
| Wan 3.0 | 动作/口播/机位严格复刻 | 干净参考视频（该段）+ 参考图 + audioUrls（换音色时）+ 分辨率 | 参考视频权重强，瑕疵会被继承，1.8 闸必过 |
| Seedance 2.5 | 画面质感、复杂换装/换景 | 参考视频 + 分类参考图（产品/脸/衣/景）+ 音色参考 | 参考图分类传，不混淆；接口不支持某类参考时标记降级，不静默丢 |

引擎在 0 步登记，**同一任务中途不静默切换**；A/B 对比须先登记两个候选、输入与成本。

## 入口校验

- 最短裁剪 1s；超级复刻不强制单段 ≤15s（超长由 `plan_15s_windows` 切）
- 尾段短于 2s 时向前一段借时
- `product_name` 空则拒绝

## 多脸

代码已支持 `extra_model_image_paths`。Agent 难单不要把多张脸一次塞进整段 prompt。按 TIMELINE 每段只传一张脸。
