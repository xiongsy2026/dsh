# Wan 3.0 边界（实操结论）

来自 video-skill 超级复刻联调，尤其是 2026-09-24 富铁软糖多脸单。

1. 参考视频单段 1–15 秒，API 按 5–15 秒档更稳。实操最短比较稳的是 **2 秒**。
2. 单段输入时长 + 输出时长 ≤ 30 秒。
3. 整段 15 秒一次送、里面要换多张脸：参考片会把原脸锁死，脸图挤不进去。
4. 2 秒里 3 个分镜 3 张脸：绑不住。
5. 弱引用「图N 中的同一位女性」会留下原脸。必须「严格按 图N」+ 五官描述。
6. 参考视频必须只切当前段，不要带前后镜。
7. 1 秒一条又慢又飘，不当主方案。不足 2 秒出 2 秒再裁。
8. Wan 直出改不了口播，成片跟原声（2026-10-13 实测：成片音轨与原片做差 -33.3dB = 参考视频的音轨被带出来）。改口播请走后处理腿 `voiceover_replace.run_narration_swap`（`voice_mode=rewrite_text`），🔴 不许在 prompt 里写新词就当"口播已改"——这条 lane 不照着念。
9. 原片烧录字幕/水印会跟着参考视频进来，prompt 里必须写死不要，抽帧还要验。
10. 分段直出对不齐时间轴时，以原片音频为时钟做毫秒裁切贴回。
11. Wan 3.0 的参考视频权重很强：参考视频中的烧录字幕、水印、旧背景和旧产品可能被继承；提交前必须使用当前段干净参考源。
12. `audioUrls` 用于目标音色参考时，必须传可访问音频 URL；`timbre_swap` 模式禁止后处理贴回原片原声。
13. Wan 的提示词修改必须基于已冻结的 Prompt 基线；升分辨率或换音色不得重新跑 MiMo 改写 Shot 表。
14. 若目标重点是画面质感或复杂视觉替换，可切换到 Seedance 2.5，但必须确认其参考视频/参考图/音频参数支持后再提交，不得静默丢传参。
15. **【已下线 2026-10-08，用户点名移除】XJAI 新腿（`video.generate/wan3` = xjai.beauty `wan3.0-video`，`wan3-prime` = `ME-wan30-1080p-1055`）与 RunningHub wan3 是两条不同的腿**（2026-10-07 实测）。XJAI 腿：
    - 支持 1080P 真出（1080×1920，非放大）；标准版 5s 档可跑，满血档 prime 需账户充值。
    - **媒体只吃公网 http(s) 链接**（本地路径直接 400）；参考视频/参考图必须走公网，用 RunningHub 公网 CDN（`wan3_client.upload_media` → `rh-hk-images-switch.xiaoyaoyou.com`，HEAD 200 验证）喂 XJAI。
    - **参考视频权重与文字 prompt 并列**（与 RunningHub Wan3 的"参考视频强事实源、动作跟视频"不同）：XJAI 契约没声明参考视频压过文字，参考视频进 `media[]`（`type=video`）后，**背景/产品会按 prompt 换、腿皮重画，但动作/机位/节奏由 prompt 文字主导**。⇒ **复刻类任务切 XJAI 腿时必须做 prompt 适配：删掉所有动作/机位/节奏/构图描述，只写"严格复刻参考视频的动作、机位、节奏与口播时间轴"，保留背景/产品/脸/字幕负向**。prompt 写满动作（照搬 RunningHub 那条 5-shot 逐秒动作）⇒ 出片按文字重画、参考视频降为弱参考（2026-10-07 1080P 实测：姿势没崩但拉袜节奏对不上原片，根因=动作描述盖住参考视频）。
    - 下载腿 `/v1/videos/{id}/content` 要带 Bearer（非免鉴权签名链）。
    - 报价：wan3=50 分/条、wan3-prime=60 分/条（占位价，首次实跑按 XJAI 上游 `usage` 校准）。
